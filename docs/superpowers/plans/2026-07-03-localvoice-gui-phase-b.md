# LocalVoice GUI Phase B (SwiftUI App) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The native macOS app: a SwiftUI window (Talk / Models / Settings / Setup) driving `localvoice serve` over the phase-A protocol, with a Swift-side global hotkey.

**Architecture:** `app/LocalVoice` holds an XcodeGen-defined project (committed `project.yml`, generated `.xcodeproj` gitignored). `EngineClient` (actor) owns the engine subprocess and decodes protocol lines into an `AsyncStream`; `AppState` (@Observable, MainActor) reduces events into view state; four views render it; `HotkeyMonitor` turns a CGEvent tap into `ptt_down`/`ptt_up`/`esc` commands. Protocol reference: `docs/gui.md` (binding, verified against the engine by phase-A tests).

**Tech Stack:** Swift 6 (Xcode 26.x installed, verified), SwiftUI, macOS 15.0 deployment target, XcodeGen, XCTest. No third-party Swift dependencies.

**Plan style note (deliberate, justified):** Protocol types, fixtures, project config, and reducer semantics are specified as complete code below — they are pure contracts derived from `docs/gui.md` and safe to author here. SwiftUI view tasks (B5–B8) are specified as behavior contracts + acceptance criteria instead of verbatim view code: the Swift compiler and XCTest are the verifier the plan author cannot run at plan time, and view code transcribed blind would fight the SDK. For those tasks the RED/GREEN cycle is: write the test/contract check, `xcodebuild test` fails or the acceptance step fails, implement, gate passes.

## Global Constraints

- All app code under `app/LocalVoice/`. The Python engine is NOT modified in this phase (protocol questions resolve in favor of `docs/gui.md`; if the doc is wrong, STOP and report — doc fixes are controller work).
- Deployment target macOS 15.0; app is NOT sandboxed (CGEvent tap requirement) and hardened runtime stays off in this phase; `Info.plist` carries `NSMicrophoneUsageDescription` (the engine child's mic prompt attributes to the app).
- Build/test gate for every task, run from `app/LocalVoice/`: `xcodegen generate && xcodebuild -project LocalVoice.xcodeproj -scheme LocalVoice -destination 'platform=macOS' test` ending in `** TEST SUCCEEDED **`. Python gates (`uv run ruff check .`, `uv run pytest -m "not slow" -q`, from repo root) must stay green (they should be untouched).
- Protocol version 1 only: on a `ready` with `version != 1` the client surfaces a fatal banner (no silent best-effort).
- UI copy: sentence case, no emoji, no exclamation marks; concise labels.
- Conventional commits. `.xcodeproj`, `build/`, `DerivedData/`, `*.xcuserstate` gitignored.
- Swift concurrency: no `@unchecked Sendable`, no `DispatchQueue` where structured concurrency serves; `AppState` is `@MainActor`.

### Task B2: Protocol types (Codable contracts)

**Files:**

**Interfaces (produced — later tasks depend on these exact names):**

```swift
enum JSONValue: Codable, Equatable { case string(String), int(Int), double(Double), bool(Bool), object([String: JSONValue]), array([JSONValue]), null }
struct SchemaField: Codable, Equatable { let key, type, section, label, help, widget: String; let value, `default`: JSONValue; let minimum, maximum, step: Double? }
struct InstalledModel: Codable, Equatable, Identifiable { let id, path, kind: String; let sizeGb: Double }   // size_gb via CodingKeys
struct Latency: Codable, Equatable { let stt, ttft, firstClause, ttsFirst, total: Double }                    // snake_case via CodingKeys
enum EngineEvent: Equatable {
    case ready(version: Int, config: JSONValue, schema: [SchemaField])
    case state(String)
    case userText(String), assistantClause(String), reasoning(String)
    case turnDone(Latency)
    case level(Double)
    case loadProgress(engine: String, phase: String, seconds: Double?)
    case enginesReady
    case downloadProgress(repo: String, pct: Double?, done: Bool)
    case models([InstalledModel])
    case configApplied(config: JSONValue, reloaded: [String])
    case error(String)
}
extension EngineEvent { static func decode(line: String) -> EngineEvent? }  // nil on unknown event name (forward compat) or bad JSON
enum EngineCommand { case pttDown, pttUp(heldMs: Int), esc, setConfig([String: JSONValue]), listModels, downloadModel(repo: String), previewVoice(voice: String), injectAudio(path: String), shutdown }
extension EngineCommand { func encodedLine() -> String }  // single-line JSON, keys per docs/gui.md, trailing "\n" NOT included
```

Implementation guidance: `EngineEvent.decode` parses with `JSONSerialization` or a `Decodable` envelope keyed on `"event"`; unknown event names return `nil` (protocol may grow); malformed JSON returns `nil`. `EngineCommand.encodedLine` emits exactly the payload keys in `docs/gui.md` (`cmd`, plus `held_ms`, `changes`, `repo`, `voice`, `path`).

@testable import LocalVoice

final class ProtocolTests: XCTestCase {
    func testDecodeState() throws {

        XCTAssertEqual(e, .state("listening"))

    func testDecodeTurnDone() throws {

        XCTAssertEqual(l.total, 0.82, accuracy: 1e-9)
        XCTAssertEqual(l.firstClause, 0.07, accuracy: 1e-9)
    }

    func testDecodeReadySchemaAndConfig() throws {
        let line = #"{"event": "ready", "version": 1, "config": {"llm": {"think": false, "max_tokens": 1024}}, "schema": [{"key": "llm.think", "type": "bool", "value": false, "default": false, "section": "Language model", "label": "Thinking mode", "help": "", "widget": "toggle"}]}"#

        XCTAssertEqual(version, 1)
        XCTAssertEqual(schema.count, 1)
        XCTAssertEqual(schema[0].key, "llm.think")
        XCTAssertEqual(schema[0].value, .bool(false))
        guard case let .object(root)? = Optional(config), case let .object(llm)? = root["llm"] else { return XCTFail("config shape") }
        XCTAssertEqual(llm["max_tokens"], .int(1024))
    }

    func testDecodeModelsAndProgressAndError() throws {
        XCTAssertEqual(
            EngineEvent.decode(line: #"{"event": "models", "installed": [{"id": "a/b", "path": "/x", "size_gb": 18.6, "kind": "mlx"}]}"#),

            EngineEvent.decode(line: #"{"event": "download_progress", "repo": "a/b", "pct": null, "done": false}"#),
            .downloadProgress(repo: "a/b", pct: nil, done: false)
        )
        XCTAssertEqual(EngineEvent.decode(line: #"{"event": "error", "message": "boom"}"#), .error("boom"))
        XCTAssertEqual(EngineEvent.decode(line: #"{"event": "engines_ready"}"#), .enginesReady)

        XCTAssertNil(EngineEvent.decode(line: "[1, 2]"))

            try XCTUnwrap(JSONSerialization.jsonObject(with: Data(s.utf8)) as? NSDictionary)

        try XCTAssertEqual(json(EngineCommand.pttUp(heldMs: 512).encodedLine()), ["cmd": "ptt_up", "held_ms": 512])

**Interfaces (produced):**

```swift
enum LaunchMode: Equatable {
    case devCheckout(URL)          // repo root; runs ["uv", "run", "localvoice", "serve"]
    case custom(executable: URL, arguments: [String])  // used by tests and later by phase C's bundled engine
}
enum ClientEvent: Equatable {
    case engine(EngineEvent)
    case spawned
    case exited(code: Int32)
    case respawning(attempt: Int, delaySeconds: Double)
}
actor EngineClient {
    init(mode: LaunchMode, autoRespawn: Bool = true)
    var events: AsyncStream<ClientEvent> { get }   // single-consumer
    func start() async
    func send(_ command: EngineCommand) async      // writes line + newline to child stdin
    func stop() async                              // sends shutdown, waits 3 s, SIGKILLs if needed; no respawn after
}
```

Behavior contract:
- Reads child stdout line-by-line (`FileHandle` readability or `bytes.lines` on the pipe), decodes via `EngineEvent.decode`, yields `.engine(...)`; undecodable lines are dropped (count them; expose `var droppedLines: Int` for tests).
- stderr is drained continuously to `Logger(subsystem: "dev.localvoice", category: "engine")` — never blocked, never parsed.
- Unexpected exit (not after `stop()`): yield `.exited(code:)`; if autoRespawn, yield `.respawning(attempt:delay:)` with delays 1, 2, 4, 8, 8, … seconds and start a fresh process.
- `send` before spawn or after death is a silent no-op (the UI gates on state anyway).

### Task B4: AppState reducer

**Files:**
- Create: `app/LocalVoice/Sources/State/AppState.swift`
- Test: `app/LocalVoice/Tests/AppStateTests.swift`

**Interfaces (produced):**

```swift
struct Turn: Equatable, Identifiable { let id: Int; var role: String  /* "user"|"assistant" */; var text: String; var reasoning: String? }
@MainActor @Observable final class AppState {
    var connection: String = "connecting"      // connecting | ready | engines_ready | dead
    var assistantState: String = "idle"        // mirror of protocol state values
    var turns: [Turn] = []
    var micLevel: Double = 0
    var lastLatency: Latency?
    var config: JSONValue = .null
    var schema: [SchemaField] = []
    var models: [InstalledModel] = []
    var downloads: [String: Double?] = [:]     // repo -> pct (nil = indeterminate); removed when done
    var loading: [String: String] = [:]        // engine -> phase, while a load/reload runs
    var banner: String?                        // latest error message; nil when dismissed
    var protocolMismatch: Bool = false
    func reduce(_ event: ClientEvent)
}
```

Reduction semantics (complete, binding):
- `.spawned` → connection = "connecting". `.engine(.ready(v, config, schema))` → stores config/schema; connection = "ready"; `protocolMismatch = (v != 1)`. `.engine(.enginesReady)` → connection = "engines_ready". `.exited` → connection = "dead". `.respawning` → connection = "connecting".
- `.engine(.state(s))` → assistantState = s (idempotent repeats fine — level-triggered per docs/gui.md).
- `.engine(.userText(t))` → append `Turn(role: "user", text: t)` then append an empty assistant turn (`role: "assistant", text: ""`).
- `.engine(.assistantClause(t))` → append (space-joined) to the LAST assistant turn's text; if none exists (defensive), create one.
- `.engine(.reasoning(t))` → set/append to the last assistant turn's `reasoning`.
- `.engine(.turnDone(l))` → lastLatency = l.
- `.engine(.level(v))` → micLevel = v; on `.state` ≠ "listening", micLevel resets to 0.
- `.engine(.loadProgress(e, p, _))` → loading[e] = p; remove key when p == "done".
- `.engine(.downloadProgress(r, pct, done))` → done ? remove : downloads[r] = pct.
- `.engine(.models(m))` → models = m. `.engine(.configApplied(c, _))` → config = c; banner = nil.
- `.engine(.error(m))` → banner = m.
- Turn ids: monotonically increasing Int (private counter).

### Task B8: HotkeyMonitor (global right-command PTT)

**Files:**
- Create: `app/LocalVoice/Sources/Engine/HotkeyMonitor.swift`
- Test: `app/LocalVoice/Tests/HotkeyLogicTests.swift`

**Contract:**
- CGEvent tap (`CGEvent.tapCreate`, session tap, listen-only) on `flagsChanged` + `keyDown`: right command = keycode 54 on `flagsChanged` (down when `flags.contains(.maskCommand)` AND keycode 54; up when keycode 54 and command bit cleared); Esc = keycode 53 on `keyDown`. Debounce/held-ms measured with `ContinuousClock` from down to up; on up, call `onPttUp(heldMs)`; on down `onPttDown()`; Esc → `onEsc()`. Tap-creation failure (no permission) → `var available: Bool` false, surfaced by SetupView's Input Monitoring card; retry via `refresh()` (called on app refocus).
- Pure helper (tested without a real tap): `enum KeyDecision { case pttDown, pttUp, esc, none }` + `func decide(type: CGEventType, keycode: Int64, commandBit: Bool, pttCurrentlyDown: Bool) -> KeyDecision` — the complete truth table: (flagsChanged, 54, true, false)→pttDown; (flagsChanged, 54, false, true)→pttUp; (flagsChanged, 54, true, true)→none; (keyDown, 53, _, _)→esc; everything else→none.
- Wire in `LocalVoiceApp`: monitor callbacks send `pttDown`/`pttUp(heldMs:)`/`esc` through the client. TalkView's on-screen button and the global key coexist (orchestrator handles repeats).
- [ ] **Steps:** failing truth-table tests → implement → gate → manual acceptance: with the app running (not focused — switch to another app), hold right ⌘ and speak; barge in mid-answer; Esc cancels. This mirrors the v1 terminal acceptance list.
